How Ratings Are Calculated

This page explains the criteria and methodology behind the rating systems displayed across the platform for both mentors and mentees.

Mentor Rating Overview

Each mentor is rated on a 5-star scale using 5 criteria

The Final Rating is the simple average of all criteria that have data. Each criterion is scored from 0 to 5 stars. The final rating is displayed on mentor cards, profile previews, and the mentor dashboard.

1

Profile Completeness

Always included

0-5 Stars

Measures how complete the mentor's profile is. A fully complete profile scores 5 stars; partial profiles score proportionally.

How it's calculated:

  • • The system checks 31 profile fields (photo, profession, skills, education, social links, mentorship preferences, etc.)
  • • Formula: (completed_fields / total_fields) × 100 = percentage, then percentage / 20 = star rating
  • • Example: 25 of 31 fields filled = 80% = 4.0 stars
2

Useful Skills

Always included

0-5 Stars

Measures the breadth and relevance of skills the mentor offers. More skills mean higher score, capping at 5 stars for 10+ skills.

How it's calculated:

  • • The system counts skills from the mentor's comma-separated skills field
  • • Formula: min(skill_count × 10, 100) = percentage, then percentage / 20 = star rating
  • • Example: 7 skills = 70% = 3.5 stars; 10+ skills = 5.0 stars
3

Task Completion

Included when tasks have been assigned

0-5 Stars

Measures task diligence and execution rate across all tasks assigned to mentees under this mentor.

How it's calculated:

  • • Part A (40%): Task completion rate across all mentorships — (completed_tasks / total_tasks) × 100 = percentage, then / 20 = stars
  • • Part B (60%): Average task rating (1-5 stars) from TaskRating records on completed tasks
  • • Formula: (completion_stars × 0.4) + (avg_task_rating × 0.6) = star rating
  • • Example: 80% completion (4.0 stars) + 4.5 avg task rating = 4.3 stars
4

Mentee Feedback

Included when mentee evaluations exist

0-5 Stars

Averages qualitative and quantitative ratings provided by mentees upon task completion and program milestones.

How it's calculated:

  • • Aggregates numeric feedback submitted by mentees in feedback entries
  • • Scores range from 1 to 5 stars per review and are averaged together
5

Mentorship Experience

Combined rating from coordinator and admin

0-5 Stars

Combines two independent quality assessments: the coordinator's per-mentorship rating and the admin's overall mentor rating.

How it's calculated:

  • • Part A — Coordinator Rating: Average of per-mentorship ratings assigned by the coordinator across all approved mentorship connections
  • • Part B — Admin Rating: Overall 1-5 star rating assigned by the admin/supervisor to the mentor
  • • Formula: (coordinator_avg + admin_rating) / 2 = star rating (when both exist); uses whichever is available
  • • Example: Coordinator rates 4.0 + Admin rates 4.5 = 4.3 stars

Final Rating Formula

Simple Average of All Rated Criteria

Final = Profile + Skills + Tasks + Feedback + Experience / N

Mentee Rating Overview

Each mentee is rated on a 5-star scale using 5 comprehensive criteria

The Final Rating is the average of all criteria that have available data. Each criterion is scored from 0 to 5 stars. The final rating is displayed across the platform on mentee directory lists, task cards, and mentee dashboards.

1

Profile Completeness

Always included

0-5 Stars

Measures how thoroughly the mentee filled out their profile (contact information, education level, stream, school, parent consent, etc.).

How it's calculated:

  • • The system assesses over 30 mentee profile fields
  • • Formula: (profile_completeness_percentage / 20) = star rating
  • • Example: 85% complete = 4.3 stars
2

Goal Clarity

Always included

0-5 Stars

Assesses the clarity and ambition of the mentee's stated goals, career aspirations, and expectations.

How it's calculated:

  • • Checks specific goal and career aspiration fields submitted by the mentee
  • • Each articulated aspiration field awards up to 2.5 stars, capped at 5.0 stars
3

Task Completion

Included when tasks have been assigned

0-5 Stars

Measures task diligence and execution rate across all tasks assigned by mentors and institutions.

How it's calculated:

  • • Formula: (completed_tasks / total_tasks * 100) / 20 = star rating
  • • Example: 8 of 10 tasks completed = 80% = 4.0 stars
4

Mentor Feedback

Included when mentor evaluations exist

0-5 Stars

Averages qualitative and quantitative ratings provided by mentors upon task completion and program milestones.

How it's calculated:

  • • Aggregates numeric feedback submitted by mentors in reflection entries
  • • Scores range from 1 to 5 stars per review and are averaged together
5

Mentorship Experience

Combined rating from coordinator and admin

0-5 Stars

Combines two independent quality assessments: the coordinator's per-mentorship rating and the admin's overall assessment of the mentorship program.

How it's calculated:

  • • Part A — Coordinator Rating: Average of per-mentorship ratings assigned by the coordinator across all approved mentorship connections
  • • Part B — Admin Rating: The admin/supervisor's evaluation of the mentorship quality for this mentee
  • • Formula: (coordinator_avg + admin_rating) / 2 = star rating (when both exist); uses whichever is available
  • • Example: Coordinator rates 3.5 + Admin rates 4.0 = 3.8 stars

Final = Profile + Goals + Tasks + Feedback + Experience / N
